# 🚦 RARIF Framework (Road Accident Risk Intelligence & Forecasting)

## 📌 Overview

RARIF is a Machine Learning-based system designed to predict road accident risk using traffic, environmental, and driver behavior data.

This project demonstrates how AI can be used for road safety and risk forecasting.

---

## ⚙️ Features

* 🤖 XGBoost Machine Learning Model
* 📊 Multi-class Risk Prediction (Low, Medium, High)
* 📈 Model Evaluation (Accuracy, F1 Score, Classification Report)
* 🔍 Explainable AI using SHAP
* 🧩 Modular Python Project Structure

---

## 🧠 Tech Stack

* Python
* Pandas, NumPy
* Scikit-learn
* XGBoost
* SHAP

## 🚀 How to Run

### 1. Clone the repository

```bash id="8s9v6h"
git clone https://github.com/yourusername/RARIF-Framework.git
cd RARIF-Framework
```

### 2. Create virtual environment

```bash id="6a1qzm"
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```bash id="m5o9fn"
pip install -r requirements.txt
```

### 4. Run project

```bash id="9knq6v"
python main.py
```
